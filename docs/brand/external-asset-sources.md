# External Asset Sources

No external production image assets are used in Phase 2.

## Decision

ROOT currently ships with original repo-native SVG/CSS visuals and temporary fallback brand SVGs only. This avoids generic healthcare stock imagery, licensing ambiguity, and accidental implied clinical or patient claims.

## Official Asset Status

Official brand asset import remains blocked. The provided ChatGPT shared asset URL resolved to an unauthenticated shell, and the local source package found in Downloads contained markdown context only, not logo or media assets.

## Future Asset Requirements

When official assets are available, record each item here with:

- Original filename.
- License or ownership status.
- Repository destination.
- Optimization performed.
- Pages/components using it.
- Approval note.
