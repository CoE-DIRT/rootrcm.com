# GitHub Pages

The site is designed for GitHub Pages static hosting.

## Requirements

- Build output: `dist-staging`.
- `public/CNAME` remains `rootrcm.com`.
- `sitemap.xml` and `robots.txt` are generated into the build output (`src/seo/`); there are no static copies in `public/`.
- Static route HTML files exist for all major routes.

Do not change DNS, nameservers, HTTPS enforcement, custom-domain settings, or production Pages settings from feature work.
