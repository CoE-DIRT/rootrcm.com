# WCAG Baseline

Target WCAG 2.1 AA for the public site.

## Current Checks

- One logical H1 per route.
- Semantic header, main, nav, section, footer, form, labels, buttons, and links.
- Keyboard-visible focus states.
- Mobile menu exposes `aria-expanded`.
- Form fields are labeled.
- No-PHI checkbox is explicit and required.
- Color contrast is designed for dark glass surfaces.
- Touch targets meet practical sizing through 48px button height.
- Reduced motion rule is present.

## Maintenance

Browser QA should include keyboard navigation, mobile menu operation, visible focus, form validation, zoom/responsive checks, and contrast review when colors change.
