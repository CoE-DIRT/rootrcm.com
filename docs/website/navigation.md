## Mega Menu Requirements

- Desktop nav groups use accessible buttons with `aria-haspopup` and `aria-expanded`.
- Each mega menu includes a hub link, short group description, child labels, and child descriptions.
- Mobile nav stacks groups in an accordion-like layout.
- The Diagnostic CTA remains visible in the header and footer.
- CTA links include `data-cta`, `data-location`, `data-destination`, and `data-engagement-type`.
