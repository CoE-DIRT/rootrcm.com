## Checks

- ROOT is positioned as a healthcare MSO platform, not only a diagnostic company.
- DIRT is positioned as the intelligence layer inside ROOT.
- Diagnostic is visible as the $2,500 paid entry offer.
- Header logo and mega navigation render.
- Mobile menu opens and remains usable.
- Primary CTAs are visible and include data attributes.
- Carousel responds to buttons and keyboard arrows.
- No horizontal overflow at required widths.
- Text does not overlap cards, buttons, menus, visuals, or forms.
- Forms require no-PHI acknowledgement.
- Fallback inquiry email and copy actions appear when no endpoint is configured.
- Focus states are visible.
- Reduced-motion media query keeps the site usable.
- Footer links resolve.
- Favicon, manifest, robots, sitemap, CNAME, and brand assets exist in build output.
