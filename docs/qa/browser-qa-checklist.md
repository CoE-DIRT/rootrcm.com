# Browser QA Checklist

Test at approximately 1440px, 1280px, 768px, and 390px.

## Routes

- `/`
- `/diagnostic/`
- `/services/rcm/`
- `/services/practice-ops/`
- `/technology/dirt/`
- `/company/about/`
- `/contact/`
- `/legal/privacy/`
- `/legal/terms/`
- `/404.html`

## Checks

- Header logo and navigation render.
- Mobile menu opens and closes.
- Primary CTAs are visible and clickable.
- No horizontal overflow.
- Cards and glass surfaces do not obscure text.
- Forms require no-PHI acknowledgement.
- Fallback inquiry email and copy actions appear when no endpoint is configured.
- Focus states are visible.
- Reduced-motion media query keeps the site usable.
- Footer links resolve.
- Favicon, manifest, robots, sitemap, CNAME, and brand assets exist in build output.
