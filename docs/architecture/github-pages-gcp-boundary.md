# GitHub Pages And GCP Boundary

## GitHub Pages

GitHub Pages serves the public website, static assets, metadata, sitemap, robots, CNAME, and deidentified inquiry experience.

## Future GCP

GCP may later support secure intake, storage, analytics, and operational services. That work requires approved architecture, secrets handling, BAAs where applicable, access controls, audit logging, and retention rules.

## Rule

The static public website must not pretend a secure backend exists. Endpoint-ready code is allowed only when the public fallback remains safe.
