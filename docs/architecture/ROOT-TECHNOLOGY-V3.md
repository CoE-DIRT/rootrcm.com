## Enforcement Rules
1. Use ROOT Technology v3 first for all new ROOT architecture, coding, deployment, QA, documentation, security, analytics, integrations, and operations.
2. Appwrite is the primary website/application platform.
3. GitHub Pages is reserved for documentation and project sites.
4. DIRT follows the same technology standard as an embedded ROOT intelligence capability unless an explicitly documented legacy exception applies.
5. Azure, Codespaces, and Termius remain on HOLD until explicitly reactivated.
6. Blockchair remains FUTURE scope until explicitly approved for production use.
7. Avoid duplicate platforms and tool sprawl. Reuse capabilities already present in ROOT Technology v3 before introducing alternatives.
8. Any deviation requires explicit approval or a documented dependency/business case.
