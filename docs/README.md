# ROOT Website Documentation

This documentation describes the actual `rootrcm.com` repository: a React/Vite static commercial website deployed by GitHub Pages.

## Map

- `architecture/` - repository shape, static routing, and GCP boundary.
- `adr/` - accepted technical and governance decisions.
- `brand/` - asset source, fallback state, and usage inventory.
- `design-system/` - Clinical Glass tokens, components, and motion rules.
- `website/` - sitemap, navigation, content, and conversion architecture.
- `seo/` - metadata, keyword map, and technical SEO baseline.
- `security/` - public-site no-PHI boundary.
- `accessibility/` - WCAG 2.1 AA baseline.
- `performance/` - static-site performance budget.
- `analytics/` - deidentified measurement plan.
- `deployment/` - local development, GitHub Pages, and release process.
- `qa/` - browser QA checklist.

Documentation is part of the product. Keep it current when implementation changes.
