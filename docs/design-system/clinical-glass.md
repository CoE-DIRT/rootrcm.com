# Clinical Glass

## Tokens

- Background: `#07110e` with deep green/charcoal gradients.
- Soft background: `#0b1814`.
- Glass panel: `rgba(16, 35, 29, 0.74)`.
- Solid fallback panel: `#10231d`.
- Border: `rgba(255,255,255,.11)`.
- Text: `#edf5f1`.
- Muted text: `#98aaa1`.
- Primary accent: `#70e0ad`.
- Data accent: `#75d7ff`.
- Warm signal accent: `#d8bd7a`.
- Radius: `8px`.
- Shadow: `0 30px 90px rgba(0,0,0,.28)`.

## Rules

- Use glass to create hierarchy, not decoration.
- Keep blur restrained and pair it with readable contrast.
- Avoid large animated blur regions.
- Avoid unsupported healthcare, security, or revenue claims.
- Use data visuals as explanatory interface language, not fabricated proof.
- Preserve mobile readability and one clear CTA path.
