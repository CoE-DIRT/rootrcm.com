# Components

## Header

Sticky dark glass header with ROOT brand, primary navigation, dropdown for Solutions, and a Diagnostic CTA.

## Buttons

Primary CTAs use the mint gradient and dark text. Secondary CTAs use transparent glass with a border. Buttons need visible focus states, hover feedback, and at least 48px touch height.

## Cards And Panels

Cards use the shared glass panel treatment, 8px radius, subtle border, and restrained hover lift. Avoid nested cards.

## Forms

Form inputs use dark translucent surfaces, clear labels, visible focus, and the mandatory no-PHI acknowledgement. Fallback state explains that nothing was stored by the static site.

## Data Visuals

Use charts, rows, scan lines, and signal panels to explain ROOT's analytical discipline. Do not present illustrative visuals as customer outcomes.
