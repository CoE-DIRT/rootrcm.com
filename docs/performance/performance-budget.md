# Performance Budget

## Budget

- Keep the public site static.
- Avoid heavy animation dependencies.
- Prefer CSS transitions and lightweight transforms.
- Keep images optimized and sized for their use.
- Avoid layout shift in the header, hero, cards, and forms.
- Keep JavaScript limited to route rendering, menu state, inquiry fallback, and metadata sync.

## Current Assets

Fallback brand assets are SVG and small. Future official raster assets should use WebP/AVIF derivatives where appropriate while preserving originals.
