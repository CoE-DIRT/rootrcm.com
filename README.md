# rootrcm.com
Official public repository for ROOT — Revenue Operations & Outcomes Technology.

ROOT is positioned as a PHI-capable healthcare Management Services Organization (MSO) platform for independent medical practices and healthcare providers. ROOT handles non-clinical administration, revenue cycle management, practice operations, compliance support, healthcare IT, reporting, and growth infrastructure so physicians can focus on patient care while maintaining clinical control.

Public website inquiry flows must remain deidentified. PHI may only be handled through approved secure channels after the proper agreements, access controls, and compliance workflows are active.

Infrastructure foundation, domain settings, DNS records, environment gates, and GCP project structure are tracked in [docs/ROOT_INFRA_FOUNDATION.md](docs/ROOT_INFRA_FOUNDATION.md).
