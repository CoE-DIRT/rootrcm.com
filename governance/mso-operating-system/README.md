# ROOT MSO Operating System v1

**ROOT - Revenue Operations & Outcomes Technology**  
Domain: `rootrcm.com`

This repository folder is a controlled, implementation-ready documentation system for a U.S. healthcare Management Services Organization (MSO) supporting independent physician practices and professional clinical entities. It is designed for ROOT's operating model: RCM + operations + technology, with DIRT as the data/analytics layer.

## Design principles

1. **Clinical independence is non-negotiable.** The PC/PLLC and licensed clinicians retain exclusive control over diagnosis, treatment, clinical protocols, supervision of clinicians, medical records decisions required by law, and other professional judgment.
2. **State law controls CPOM and fee-splitting.** This pack supplies a state-readiness matrix and reserved-powers model; it does not assume one structure works in all states.
3. **HIPAA minimum necessary + security by design.** Public GitHub is for sanitized templates only. Restricted Drive/GCP is for executed agreements, evidence, audit logs, credentials, security artifacts and any PHI/ePHI.
4. **Evidence beats policy theater.** Each program includes logs, registers, owners, frequencies, tests and corrective-action mechanisms.
5. **Standards-aligned, not certification-claimed.** Controls are organized to map to HIPAA/HITECH, HHS-OCR guidance, HHS-OIG compliance guidance, NIST CSF 2.0, NIST SP 800-66 Rev. 2, and selected ISO management-system concepts (ISO 9001, ISO/IEC 27001/27701, ISO 22301).

## Folder map

The complete modular v1 pack contains 30 controlled modules plus a master register, consolidated master document and machine-readable register. The consolidated master will be committed alongside this README; the modular source ZIP is also available from the project working package.

## Storage rule

**GitHub (sanitized):** policies, SOPs, blank forms, architecture descriptions, control mappings, code, synthetic examples.  
**Restricted Drive/GCP:** signed MSAs/BAAs, provider files, payer contracts, FMV reports, personnel records, completed audit/risk/incident logs, screenshots containing identifiers, PHI/ePHI, credentials, API keys, secrets.

## Approval gate before commercial use

- Entity and state structure validated by U.S. healthcare counsel.
- MSA / PC governance / fee methodology reviewed for each operating state.
- Privacy and Security Officers assigned.
- Security Risk Analysis completed and risk treatment approved.
- BA/vendor inventory complete; BAAs executed where required.
- RCM compliance audit baseline completed.
- Incident response + backup restore test completed.
- Workforce training and sanctions process live.
