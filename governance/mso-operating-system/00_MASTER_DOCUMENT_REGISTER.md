## Classification model

- **PUBLIC:** marketing/public information only.
- **INTERNAL:** non-sensitive internal instructions.
- **CONFIDENTIAL:** proprietary policies, process design, sanitized security architecture.
- **RESTRICTED:** PHI/ePHI, workforce/provider records, signed contracts, financial evidence, incident/audit evidence, credentials, detailed security evidence. Never store in public GitHub.

## Document lifecycle

Draft -> SME review -> Compliance review -> Counsel review where flagged -> Approval -> Effective -> Training/implementation -> Evidence capture -> Periodic review -> Superseded/archived.

Every approved policy must have: unique ID, owner, approver, effective date, version, review date, revision history, related forms/evidence, and retention rule.
